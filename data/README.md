# Processed cotton dataset

Each contrast table contains 62,257 genes, in a common feature schema. DEG labels differ by experimental contrast:

| Table | Contrast | DEG positives |
|---|---|---:|
| `cotton/clients/c1_cotton_nitrogen/train_ready.tsv` | HN-WT versus LN-WT | 3,143 |
| `cotton/clients/c2_cotton_mutant/train_ready.tsv` | HN-AS98 versus HN-WT | 2,474 |
| `cotton/clients/c3_cotton_salt/train_ready.tsv` | WT-salt versus WT-mock | 16,104 |

The nitrogen and mutant contrasts share HN-WT libraries. The binary label is 1 for adjusted p < 0.05 and absolute log2 fold change > 1; otherwise it is 0.

Columns: `gene_id`; 23 stored feature columns; `label`; `log2FoldChange`; `padj`. The model uses 20 active features in the paper protocol (`--cotton-feature-set no-expression`):

- ATAC (5): `atac_prom_HN_AS98`, `atac_prom_HN_WT`, `atac_prom_LN_AS98`, `atac_prom_LN_WT`, `atac_prom_mean`.
- ChIP (5): `drebind_occ_4`, `drebind_occ_5`, `drebind_occ_6`, `drebind_occ_mean`, `drebind_occ_sd`.
- Sequence (6): `gc`, `DRE_full`, `DRE_core`, `ABRE`, `G_box`, `GCC_box`.
- Structure (4): `gene_len`, `n_exon_blocks`, `exon_len_total`, `exon_fraction`.

The three stored `expr_*` features are excluded by masking at the loader boundary. They must not be enabled for the paper's primary experiment.

`cotton/metadata/gene_families.tsv` maps gene identifiers to family identifiers. Within these dataset genes, all mapped families are singletons. Runtime seeded splits therefore separate genes, not homologous groups. Splits and train-only standardization are generated by `utils/cotton_dataset.py`; no pre-generated split, prediction scores or log files are included.

These are processed research data, not the original sequencing reads, alignments, experimental sample sheet or complete raw-data archive. Treatment concentrations, sampling details and biological-versus-technical replicate identities cannot be established from these tables alone.
